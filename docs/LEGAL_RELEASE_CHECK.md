# Legal and attribution release check

- In-app privacy notice and terms describe the current implementation. Owner must review before public release, confirm legal identity/contact/retention practices and applicable obligations, and publish a publicly accessible privacy policy URL for store submission.
- Google OSS licenses plugin and SDK (official guide: https://developers.google.com/android/guides/opensource) generate and display library notices from the resolved build metadata. Build and inspect notices; dependency metadata is not proof that all obligations are satisfied.
- Manrope font notice copied from https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt; confirm bundled font provenance matches before distribution.
- Reaudit merged manifest, dependencies, actual data handling, payments and media operations before launch and after feature changes. No public registration or certification is asserted.
