# Phase 02: actual duplicate review
Read-only scan groups supply real URI thumbnails, sizes and names. Nothing selected by default. Keep first item, prefer favorite as keeper, exclude all favorites. Explicit selection up to 100 and revalidation budget 1 GB. Verify selected copies and keeper against scan SHA-256, current size, pending/trash state, current favorite state, and permission before creating Android MediaStore trash request. Android 11+ only; older versions read-only. No direct delete or update. System approval is required; RESULT_OK is reported as Android-confirmed trash, never as bytes freed. Cached scan invalidated before returning to review. Revalidation cannot guarantee against other apps changing media after the system prompt opens. Memory Guard custom rules and persistent history are not connected yet. Review on a physical device with disposable files before release.
