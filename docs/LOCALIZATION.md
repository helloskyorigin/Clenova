# Localization

Native Android app-language integration with a persistent legacy locale override on API 26–32. The selector lists 15 languages and a device-language option. All 318 translatable resource keys are present in each additional language (4452 localized entries). Settings, Clean and real Smart Scan are localized. Third-party license texts retain original wording. Run tools/check_localization.py. Resource coverage is not native-speaker or device verification.
