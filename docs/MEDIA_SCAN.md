# Phase 01: read-only Android media scanner

User-triggered permission request on API 26–32 (read external storage), API 33 (read images/video), API 34+ (including selected visual media). No broad all-files access, write permission, network upload, background scheduling or deletion. Reads MediaStore image/video collections on mounted shared volumes, ignores pending/trashed items where supported. Same-size candidates are hashed with full SHA-256, checking stream length; unreadable or changing items are skipped. Screenshots are name/folder heuristics; large videos >=100 MB. Categories may overlap, union byte total is deduplicated and described as review space, not guaranteed recovery. Caps: 20,000 media items and 1 GB of hashing per scan; incomplete status is shown if caps or skipped entries occur. Scan work runs on IO, cancel checks between rows/chunks, permission checked again before publishing. In-memory results only; clear when app stops. Clean displays real summary and counts after scan, no synthetic results. Phase 2 will implement duplicate review/deletion, phase 3 similarity, phase 4/5 category reviews, phase 8 guard integration. No actual deletion or protection yet. Device testing and APK build remain required.
