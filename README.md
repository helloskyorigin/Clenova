# Clenova — Home design phase

Native Android Java prototype. Launches directly into the approved Home screen. Uses sample data only: score 92, 42.8 GB available, 12.4 GB recovered, 4.8 GB proposed recovery. No device permissions or network access. No real scanning, deletion, Agent, billing or other screens yet.

## Build
JDK 17, Android SDK 35, Gradle 8.9 (AGP 8.7.3). Run `./gradlew :app:assembleDebug` from the repository root. Windows: `gradlew.bat :app:assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`. The repository can be imported into Android Studio.

## Visual acceptance
- Light gray background, black header, blue Pro pill, circular Settings.
- No app-drawn status bar; OS status bar hidden in this preview.
- Autopilot status, animated segmented gauge, score/label, last checked text.
- Available / recovered storage summary and segmented storage bar.
- Agent approval card, privacy line and pinned 3+1 navigation.
- Other navigation targets and approval are explicitly preview dialogs; no destructive behavior.
- On shorter screens content scrolls while the bottom navigation remains visible.
- Screen layout based on user-approved screenshots. Device/emulator validation required before claiming pixel-perfect fidelity.

## Phase 44 — Speaker Cleaner

## Phase 45 — Internet Speed Test
Four native screens: ready/GO, live throughput dial and graph, measured results with advisory connection experience, and the latest 50 local results with sharing and clear-history confirmation. Uses the documented Cloudflare HTTPS measurement paths (`/__down?bytes=N` and `/__up`) for preview, with an explicit data-use/IP disclosure before each test. HTTP latency is the median of five timed requests after a warm-up; jitter is mean absolute consecutive latency difference; neither is ICMP or packet loss. Download and acknowledged upload throughput use actual payload bytes and elapsed wall time (including HTTP overhead and request setup). Adaptive requests are limited to 24 MB download + 12 MB upload on unmetered networks or 6 MB + 3 MB on metered networks, plus acknowledgement and protocol overhead, and each test targets six seconds per transfer phase subject to a 45-second watchdog. No personal files or account data are sent; synthetic payload only. Native active-network detection, cancellation, foreground lifecycle, network-switch guards, secure HTTP status validation and timeouts. No incomplete result saved; history is bounded and included in app-data reset. Source math regression tests included in CI; local matching math sources passed javac/java checks. Navigation smoke checks do not consume test data. Endpoint access, device measurement and production third-party service terms/capacity are not yet verified; review before public release. All seven Tools entries now have dedicated source implementations.
